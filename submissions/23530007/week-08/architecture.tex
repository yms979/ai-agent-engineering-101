\parbox{27.6cm}{\sffamily\scriptsize
\textcolor{violet!70!black}{\textbf{Opus agents}} decide (shop, buyer) and interpret the market (curator); \textcolor{blue!60!black}{\textbf{code}} trades at order speed and measures; \textcolor{teal!60!black}{\textbf{memory}} is files reached through tools, the curator's digest and each strategist's scored episodes and lessons; \textcolor{orange!70!black}{\textbf{watchers}} push to the user's phone and bring the user's messages back; \textcolor{red!60!black}{\textbf{humans}}: the user sets goals and big calls (chat or ntfy), the operator (Claude Code) turns them into code and notes.\\
\textbf{Kit base form vs this:} the kit runs one rule seller and one buyer per order. Here a code trading layer is steered through bounded knobs by two Opus strategists that diagnose before moving and are scored on their predictions (a miss reverts the move); a third Opus agent is the shared memory and market-intelligence hub; A/B arms are judged on score per order; and alerts plus a two-way phone channel tie the user and the operator into the loop.}
